Pulse Weather OS

A practical desktop built for weather observation, radar analysis, forecasting, and field operations.

Development build — not all planned applications are available yet.

Start here

Use the application menu to open the desktop tools installed in this build. Network access is required for live weather feeds. Check each data source's timestamp and status before relying on it.

Weather data integrity

Pulse must distinguish live observations, archived products, model guidance, and experimental analysis. Simulated or illustrative output must never be presented as a live observation or an official warning.

Project status

This is an early development image. The custom weather application suite and Supercell Wx integration are still under development. Do not use this build as an operational warning system.
